# 17lab · LinkedIn assets

Repositorio publico de solo alojamiento. Guarda las imagenes de los borradores de LinkedIn generados automaticamente para 17lab.pro, para que la API de Buffer pueda leerlas por URL publica (no admite subida directa de archivos).

No contiene codigo ni logica. El contenido lo escribe el GitHub Action del repo principal (`17lab-proyect`).

Las imagenes viven en `posters/<fecha>-<slug>.png`.
